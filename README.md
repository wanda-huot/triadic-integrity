# The Triadic Integrity Framework

**Status:** Working draft  
**Author:** Gwendolyn Huot  
**Project umbrella:** Framecraft  
**Repository purpose:** Canonical notes, working drafts, examples, and agent-readable materials for developing the framework.

---

## Overview

The Triadic Integrity Framework is a working model for describing how experience, action, and meaning become coherent.

At its simplest, the framework asks:

- What is trying to happen?
- What can the system actually hold?
- What needs to be adjusted so the whole thing works?

The framework is organized around a triadic pattern:

1. **Forces** — what generates movement, salience, pressure, desire, or direction.
2. **Capacities** — what can hold, support, limit, structure, or bear those forces.
3. **Operations** — what the system can do to adjust, adapt, respond, and form coherence over time.

The goal is not to create a closed theory of everything. The goal is to build a practical, disciplined grammar for noticing patterns in lived experience, work, relationships, creative practice, self-regulation, and meaning-making.

## Current status

This repository is an early working draft.

It is being developed in public-facing Markdown so that the framework can be:

- read by humans,
- reused by AI agents,
- tested through examples,
- revised over time,

Many parts are provisional. Some files are canonical working drafts; others are exploratory.

## What this framework is for

The Triadic Integrity Framework is meant to help with:

- diagnosing stuckness without reducing it to one cause,
- distinguishing forces, capacities, and adaptive operations,
- mapping different self-help, therapeutic, philosophical, and practical frameworks by function,
- creating clearer prompts for AI-assisted reflection,
- building human-facing registers that translate the same deep structure into different domains,
- and testing whether a simple triadic grammar can support practical insight.

It is not a clinical tool, a spiritual doctrine, a personality system, or a replacement for existing human expertise.

---

## Intellectual background

The framework has some loose resonance with triadic traditions of thought, including Peircean themes such as quality, encounter, and continuity. That resemblance is useful background context, not a formal derivation.

This is not a Peirce scholarship project, and the framework does not depend on Peirce for its validity.

The framework should be judged by whether its distinctions help people notice, diagnose, communicate, and respond more clearly.

## Core architecture

The framework is organized into three articulation layers.

### Layer 0: The Structural Layer

Layer 0 names the most basic structural primitives:

- **Quality** — felt salience, tone, vividness, character.
- **Contact** — encounter, friction, reality, relation.
- **Continuity** — pattern, persistence, form, recognizability.

These primitives form dyads, and the dyads generate a field of possible triadic coherence.

Layer 0 is abstract, descriptive, and non-diagnostic.

### Layer 1: The Mechanical Layer

Layer 1 translates the structural primitives into a more mechanical ontology.

It currently contains three main systems:

- **The Three Forces** — what generates movement or directional pressure.
- **The Three Capacities** — what can hold, support, limit, or bear that pressure.
- **The Three Operations** — what the system can do to adapt, adjust, and stabilize.

Layer 1 is the main diagnostic layer of the framework.

Its core diagnostic states are:

- **Slack** — under-formed, under-powered, vague, loose, or insufficiently connected.
- **Tight** — over-constrained, pressured, brittle, rigid, or over-controlled.
- **Misdirected** — skewed, misaligned, wrongly aimed, or distorted in orientation.
- **Coherent Formation** — the well-formed condition in which the system holds together responsively.

### Layer 2: Human Registers

Layer 2 translates the framework into human-facing language.

A register is a way of speaking the framework for a particular audience, use case, or domain.

Current and emerging registers include:

- **The Three Pulls Register** — the original formative human-facing version of the framework.
- **The Working Register** — for work, projects, effort, burnout, and practical prioritization.
- **The Embodied Register** — for felt experience, self-regulation, affect, and bodily awareness.
- **The Kid Register** — for child-friendly emotional and practical language.
- Additional proposed registers for relational, narrative, cognitive, creative, spiritual, caregiving, family-system, and other domains.

Registers are translations, not separate frameworks.

## Expression formats

Expression formats are the forms the framework can take so it can be stored, displayed, taught, used, or executed.

Examples include:

- a GitHub Markdown repository,
- printable PDFs,
- diagrams,
- structured data files,
- a public website,
- agent prompts,
- interactive tools,
- and physical models.

Layer 2 registers describe how the framework speaks.

Expression formats describe how the framework appears, circulates, and operates.
