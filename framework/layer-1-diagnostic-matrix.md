# The Layer 1 Diagnostic Matrix

The Layer 1 Diagnostic Matrix crosses the 21 Layer 1 components of the Triadic Integrity Framework with the three diagnostic distortion states.

There are 63 rows total:

- 3 Layer 1 systems
- 7 components per system
- 3 distortion states per component

The matrix is intended as a reference grammar for diagnosing where a triadic system has lost coherent formation.

The three distortion states are:

- ∿ Slack — insufficient activation, tension, support, or relation.
- ≡ Tight — over-constrained, over-pressurized, rigid, or excessive activation.
- ↯ Misdirected — skewed, misaligned, wrongly aimed, or distorted relation.

The well-formed condition is:

- ✓ Coherent Formation — the component is functioning in balanced relation to the whole.
