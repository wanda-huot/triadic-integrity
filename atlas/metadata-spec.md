# Framework Atlas — Metadata Specification (Provisional v0.3)

## Purpose

The Framework Atlas is a structured map of frameworks, theories, modalities, traditions, systems, discourse layers, and operating systems for being human.

The Atlas is intended to:
- map how humans understand self, mind, society, meaning, and transformation
- compare frameworks without prematurely collapsing them into one meta-system
- preserve relationships between traditions and ideas
- capture both elite/intellectual and vernacular/popular systems
- function as a graph of related meaning systems rather than a rigid taxonomy

The Atlas includes:
- academic theories
- therapeutic modalities
- contemplative traditions
- self-help systems
- internet-native discourse systems
- political and cultural operating systems
- folk psychologies and vernacular metaphysics
- organizational and institutional frameworks
- aesthetic and subcultural meaning systems

---

# Structural Philosophy

The Atlas develops in progressive passes rather than requiring complete metadata immediately.

## Stage One
Capture Layer + Structural Layer

Goal:
rapidly capture entities with minimal but disciplined metadata.

## Stage Two
Genealogical Layer

Goal:
map inheritance, influence, opposition, translation, and historical emergence.

## Stage Three
Anthropological Layer

Goal:
surface implicit assumptions about:
- human nature
- suffering
- transformation
- agency
- selfhood
- meaning
- society

## Stage Four
Comparative / Graph Layer

Goal:
develop:
- cross-framework comparison
- clustering
- tensions
- bridges
- overlaps
- incompatibilities
- ecosystem maps

# Stage One Metadata Specification

(Stage One = Capture Layer + Structural Layer)

Goal:
high signal, low friction, objective-first metadata.

---

## REQUIRED FIELDS

These should appear on almost all Stage One entries.

---

### Entry kind

Defines what sort of thing the entity is.

Controlled vocabulary:

```markdown
- Person
- Named system
- Person-associated approach
- Tradition/school
- Practice/modality
- Concept
- Field/discipline
- Text/work
- Institution/community
- Movement/community
- Discourse layer
```

Notes:
- Use “Person-associated approach” when a thinker’s style functions like a reusable lens.
- Use “Discourse layer” for circulating vernacular language systems (e.g. TikTok therapy-speak).

---

### Primary domain

The entity’s main intellectual or practical area.

Examples:

```markdown
psychology
philosophy
cognitive science
systems theory
religion
anthropology
self-help
politics
design
therapy
organizational theory
internet culture
```

May contain multiple domains.

---

### Territory

The broad human territory the framework operates within.

This is orthogonal to Entry kind.

Examples:

```markdown
systems thinking
vernacular metaphysics
organizational culture
internet identity
folk psychology
political ideology
contemplative spirituality
symbolic interpretation
meme ecology
relationship systems
learning systems
subculture
```

A framework may occupy multiple territories.

---

### Register

How the framework socially circulates.

Examples:

```markdown
academic/scholarly
clinical/professional
popular
internet-native
traditional/lineage-based
professional
subcultural
```

Multiple allowed.

---

### Domain

The practical domain(s) of application.

Examples:

```markdown
therapeutic
epistemology
identity-formation
organizational
spiritual-contemplative
political
educational
relational
embodiment
creative
economic
```

Multiple allowed.

---

### Brief neutral description

2–5 sentence objective summary.

Guidelines:
- avoid advocacy
- avoid premature critique
- preserve internal self-description where possible
- describe functionally rather than polemically

---

### Status

Current metadata completeness.

Controlled vocabulary:

```markdown
captured (Layers 1–2)
captured (Layers 1–3)
captured (Layers 1–4)

genealogy pending
human-picture pending
comparative mapping pending
```

# CONDITIONAL STAGE ONE FIELDS

Use when relevant and reasonably obvious.

---

## Associated person / people

Used for:
- systems
- modalities
- texts
- traditions
- concepts

Examples:

```markdown
Associated person:
Carl Jung
```

or:

```markdown
Associated people:
John Bowlby, Mary Ainsworth
```

---

## Known for

Mostly used for people.

Examples:

```markdown
Known for:
attachment theory, developmental psychology
```

---

## Claimed problem / diagnostic

One of the most important fields.

Captures:
- what problem the framework thinks humans have
- what kind of stuckness it diagnoses

Examples:

```markdown
Claimed problem / diagnostic:
Modern individuals become psychologically fragmented through disconnection from symbolic life.
```

This is NOT the same as implicit anthropology.

---

## Implicit human-picture

The Atlas’s deepest interpretive field.

Captures:
- what sort of being a human is assumed to be
- what capacities, drives, or structures humans possess
- what transformation means

Examples:

```markdown
Implicit human-picture:
Humans are symbolic and mythic beings shaped by unconscious archetypal structures.
```

Important:
- do not force this field
- many entries will remain incomplete at Stage One

---

## Draws on

Graph edge field.

Examples:

```markdown
Draws on:
- cybernetics
- ecology
- pragmatism
```

---

## Adjacent to

Neighboring frameworks.

Examples:

```markdown
Adjacent to:
- phenomenology
- systems theory
```

---

## Parent tradition of

Historical descendant relationship.

Examples:

```markdown
Parent tradition of:
- CBT
- cognitive science
```

---

## Popularizes

Used for translation figures.

Examples:

```markdown
Popularizes:
- Stoicism
- mindfulness
```

---

## Reacts against

Oppositional relationship.

Examples:

```markdown
Reacts against:
- behaviourism
- reductionism
```

---

## Contested in / Embraced in

Sociology-of-knowledge field.

Examples:

```markdown
Contested in:
- academic neuroscience

Embraced in:
- trauma therapy
- somatic practice
```

This replaces simplistic “controversial/not controversial.”

---

## Key text(s) / source(s)

Examples:

```markdown
Key text(s) / source(s):
- The Structure of Scientific Revolutions
- Discipline and Punish
```

---

## Approximate era

Examples:

```markdown
Approximate era:
mid-20th century
```

Use loosely.
