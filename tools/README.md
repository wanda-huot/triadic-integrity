# Tools

Practical uses of the Triadic Integrity Framework for diagnosis, reflection, decision-making, planning, practice, and action.

Tools are part of the Applied Framework. They differ from Registers (which translate the framework into domain-specific language) in that they are functional artifacts — things you use, not just things you read.

## Planned tools

- Diagnostic check-in prompts (single-scale and cross-scale)
- Scale identification guide (which Layer 2 scale is most relevant?)
- Distortion pattern cards (Slack / Tight / Misdirected)
- Coherent Formation mapping worksheet
