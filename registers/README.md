# Registers

Human Registers are part of the **Applied Framework**. They translate the Triadic Integrity Framework into usable language for specific audiences, domains, or situations.

Registers are not Layer 2. Layer 2 is Recursive System Scales (a structural layer). Registers are applied translations built on top of the Core Framework.

## What makes a valid register

A register should:
- translate clearly from Layer 1 canonical structure
- remain traceable back to Layer 0 and Layer 1
- serve a specific audience, domain, or use case
- not redefine the canonical structure — only translate it
