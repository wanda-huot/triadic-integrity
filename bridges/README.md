---

## Purpose

Bridges are comparative translation documents.

They connect The Triadic Integrity Framework with external frameworks, theories, traditions, modalities, or vocabularies.

A Bridge asks:

```text
How does The Triadic Integrity Framework relate to another system?
```

---

## What Bridges are

A Bridge identifies:

- useful resonances
- possible translations
- mismatches
- limits
- cautions against overclaiming

A Bridge is not meant to prove that two systems are the same.

It is meant to clarify what can and cannot be translated between them.

---

## Bridges are not Human Registers

Human Registers translate The Triadic Integrity Framework into usable language for a particular audience, domain, or situation.

Bridges compare The Triadic Integrity Framework with an external system.

Key distinction:

```text
Human Registers = how the framework speaks.
Bridges = how the framework compares and translates across systems.
Expression Formats = how the framework appears, circulates, and operates.
```

## Working rule

When creating a Bridge, ask:

```text
What translates cleanly?
What only loosely resonates?
Where does the comparison break?
What should not be claimed?
What does this comparison help us see?
```
